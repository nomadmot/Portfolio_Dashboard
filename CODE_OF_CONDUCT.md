*Code of Conduct for Portfolio Dashboard*

**Our Pledge**

We, the contributors and maintainers of Portfolio Dasboard, are committed to providing a welcoming, inclusive, and harassment-free environment for everyone, regardless of background, identity, or experience level.
We expect all participants to follow this Code of Conduct when interacting in project spaces, including but not limited to:

- GtHub repositories (issues, pull requests, discussions)
- Public forums (e.g., mailing lists, Slack/Discord, conferences)
- Social media (if applicable)
- In-person events (if applicable)

***Expected Behavior***

To that end, we require participants to Be Respectful
- Treat everyone with dignity and respect.
- Avoid personal attacks, insults, or derogatory language.
- Disagree with ideas, not people.

***Be Collaborative***

- Contribute constructively to discussions and code.
- Give and receive feedback gracefully.
- Assume good intent unless proven otherwise.
- Be Inclusive

***Acknowledge and celebrate diversity in backgrounds, experiences, and perspectives.***

- Avoid stereotypes, slurs, or exclusionary language.
- Make an effort to understand and accommodate different communication styles.
- Be Transparent

***Communicate clearly and honestly.***

- Disclose conflicts of interest or biases when relevant.
- Give credit where it’s due.
- Follow Project Guidelines

***Adhere to the project’s technical standards (e.g., coding style, documentation).***

- Report bugs/issues responsibly (e.g., no spam, no off-topic requests).
- Follow the project’s contribution process (e.g., pull request templates).

**Unacceptable Behavior**

The following behaviors are not tolerated and may lead to immediate removal from the project:
- Harassment (e.g., slurs, threats, intimidation, unwanted sexual attention).
- Public or private derogatory remarks about gender, race, religion, sexual orientation, disability, or other protected characteristics.
- Deceptive or malicious behavior (e.g., impersonation, plagiarism, spam).
- Violations of copyright or intellectual property rights.
- Repeatedly interrupting or dominating discussions.

**Consequences of Violations**

If someone violates this Code of Conduct, the project maintainers may take any or all of the following actions:
- Issue a warning (public or private).
- Temporarily or permanently ban the individual from project spaces.
- Report the individual to external platforms (e.g., GitHub, social media) if necessary.
- Involve law enforcement if the behavior is illegal.
- We reserve the right to remove content (e.g., comments, issues) that violates this CoC.

***How to Report Violations***

If you witness or experience behavior that violates this Code of Conduct, please contact the project maintainer, github@nomadmot.con

***Attribution***

This Code of Conduct is inspired by the Contributor Covenant, version 2.1, available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

***Why This Matters***

A healthy community thrives on respect, trust, and mutual support. By adhering to this CoC, we ensure that Portfolio Dashboard remains a place where everyone—from beginners to experts—can learn, grow, and contribute without fear.
